# BMI Calculator | Web Development Project

A simple, responsive, and user-friendly **Body Mass Index (BMI) Calculator** built using HTML, CSS, and JavaScript.

## 📌 About the Project

This project helps users calculate their BMI by entering their height and weight. It supports both metric and imperial measurement systems and displays the corresponding BMI category.

The project is part of my web development learning journey, combining my understanding of frontend technologies, design ideas, experimentation, and AI-assisted improvements to create a clean and interactive user experience.

## ✨ Features

- **Dual Unit Support:** Switch between Metric (kg, cm) and Imperial (lb, in).
- **Instant BMI Calculation:** Calculate BMI using the appropriate formula.
- **BMI Categories:** Identify Underweight, Normal Weight, Overweight, or Obese ranges.
- **Input Validation:** Displays helpful messages for missing, invalid, or unrealistic values.
- **Reset Option:** Clear the form and calculate again.
- **Responsive Design:** A clean layout suitable for different screen sizes.
- **Interactive Interface:** Smooth focus states, button effects, and color-coded results.
- **Accessibility:** Labels, keyboard focus indicators, and accessible result announcements.

## 🛠️ Technologies Used

- **HTML5** — Structure and semantic elements
- **CSS3** — Styling, gradients, responsive layout, and visual effects
- **JavaScript** — BMI calculations, unit switching, validation, and dynamic results
- **AI-assisted tools** — Exploring ideas and refining the design and user experience

## 🧮 BMI Formula

**Metric:**

BMI = Weight (kg) / Height (m)²

**Imperial:**

BMI = 703 × Weight (lb) / Height (in)²

## 📊 BMI Categories for Adults

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |

*BMI is a general screening measure, not a medical diagnosis. These categories are intended for adults and may not apply to everyone.*

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or run it using the Live Server extension.
5. Enter your height and weight, choose the appropriate unit system, and click **Calculate**.
