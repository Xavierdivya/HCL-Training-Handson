# 🚗 DriveEase – Car Rental Website

## 📌 Project Description

DriveEase is a responsive car rental website developed using HTML, CSS, and Bootstrap 5.3.3. The website allows users to explore available cars, view rental prices, fill out a booking form, learn about the company, and read customer feedback.

The project focuses on practicing Bootstrap components, responsive layouts, navigation, cards, forms, and custom CSS styling.

## ✨ Features

- **Responsive Navigation Bar:** Navigate between different sections of the website.
- **Home Section:** Introduces the DriveEase car rental service with navigation buttons.
- **Available Cars:** Displays three cars with images, descriptions, and daily rental prices.
- **Car Booking Form:** Collects customer details, selected car, pickup and return dates, and pickup location.
- **About Us:** Provides information about the company and its services.
- **Feature Cards:** Highlights vehicle selection, affordable prices, and reliable service.
- **Customer Feedback:** Displays sample customer reviews and star ratings.
- **Footer:** Includes quick navigation links and contact information.
- **Custom Styling:** Uses a dark theme, cyan highlights, hover effects, and a background image.
- **Smooth Scrolling:** Provides smooth navigation between website sections.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **CSS3** – Adds custom styling, transitions, and responsive design.
- **Bootstrap 5.3.3** – Provides responsive grid layouts, navigation components, cards, buttons, and form controls.
- **Bootstrap Icons and Components:** The project uses Bootstrap components and emoji characters for visual elements; no separate Bootstrap Icons library is included.
- **Unsplash Images** – Supplies car images and the home section background.
- **JavaScript Bundle** – Enables Bootstrap interactive components such as the collapsible mobile navigation menu.

## 📋 Booking Form Details

The booking form collects the following information:

- Full name
- Email address
- Selected car
- Pickup date
- Return date
- Pickup location

The form uses HTML required-field validation. A backend or booking-processing system is not implemented in the current project, so the form does not yet create or store actual reservations.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Keep `index.html` and `Car_Rental.css` in the same folder.
3. Add the `car.jpeg` favicon file if available.
4. Open `index.html` in a modern web browser.
5. Ensure you have an internet connection to load Bootstrap from the CDN and retrieve the remote car images.
6. Use the navigation bar to explore the different sections of the website.
7. Browse available cars and fill out the booking form to practice the interface.
