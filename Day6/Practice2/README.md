# ⚡ ElectroZone – Electronics & Gadgets Shopping Website

## 📌 Project Description

ElectroZone is a front-end electronics and gadgets shopping website developed using HTML, CSS, and Bootstrap. The website showcases a variety of electronic products and provides a modern shopping interface with a promotional home section, product cards, organization information, customer feedback, and contact details.

This project was created to practice Bootstrap components, responsive layouts, navigation menus, cards, buttons, and custom CSS styling.

## ✨ Features

- **Responsive Navigation Bar:** Navigate between Home, Products, About Us, Feedback, and Contact Us sections.
- **Mega Sale Banner:** Displays promotional content and shopping buttons.
- **Product Showcase:** Presents electronics and gadgets through product cards.
- **Product Pricing:** Displays product prices and Buy Now buttons.
- **About Us Section:** Describes the ElectroZone organization, mission, vision, and goals.
- **Customer Feedback:** Displays sample customer reviews and star ratings.
- **Contact Information:** Includes customer support details and working hours.
- **Social Media Links:** Provides Instagram and Facebook links.
- **Custom Styling:** Uses background images, hover effects, shadows, and modern layouts.
- **Responsive Layout:** Uses Bootstrap grid classes to help arrange content across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structures the web page.
- **CSS3** – Adds custom styling, colors, backgrounds, and animations.
- **Bootstrap** – Provides layout utilities, cards, buttons, navigation components, and responsive grid classes.
- **JavaScript Bundle** – Intended to support interactive Bootstrap components.
- **Unsplash** – Provides remote images for the product showcase and background.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Keep `index.html` and `Electronicwebpage.css` in the same directory.
3. Add the `Electronic.jpg` favicon file if available.
4. Open `index.html` in a modern web browser.
5. Ensure an internet connection is available to load external images and Bootstrap resources.
6. Navigate through the page to explore the products, organization details, customer feedback, and contact information.

## ⚠️ Limitations

- This is currently a front-end demonstration project.
- Product information is hardcoded in the HTML.
- The Buy Now buttons do not implement a purchasing workflow.
- The search field does not currently filter products.
- Customer feedback is displayed as sample content.
- No backend, database, payment system, or order management is implemented.
- External resources require an internet connection.
