# Food Menu Management System

A full-stack web application for managing food categories,
food items, prices, availability and displaying the food menu.

## Technology Stack

### Frontend
- Angular
- TypeScript
- Bootstrap

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core

### Database
- Microsoft SQL Server

### Tools
- Visual Studio
- Visual Studio Code
- SSMS
- Postman
- Git and GitHub

## Main Modules

1. Dashboard
2. Category Management
3. Food Item Management
4. Customer Menu Display
5. Search, Filtering and Pagination

## Project Architecture

Angular → ASP.NET Core Web API → EF Core → SQL Server
