# Day 8 – Vehicle Rental System

A C# console-based application developed as part of HCL training hands-on practice. This project manages vehicle rentals, customer registration, vehicle availability, rental cancellation, return processing, and payment calculations.

## Technologies Used
- C#
- .NET
- Visual Studio Community 2026

## Key Features
- Display and search available vehicles
- Sort vehicles by daily rental rate
- Register customers with input validation
- Rent and cancel vehicles
- Calculate rental charges and discounts
- Process cash and card payments
- Generate rental summaries

## OOP Concepts Practiced
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces

## C# Concepts Practiced
- Classes, objects, and properties
- Abstract classes and interfaces
- Method overloading and overriding
- Arrays and collections
- Structs and records
- Tuples and switch expressions
- `ref`, `out`, and `in` parameters

## How to Run

1. Open the project in Visual Studio.
2. Ensure the required .NET SDK is installed.
3. Build and run the console application.

Alternatively, open a terminal in the project directory and run:

```bash
dotnet restore
dotnet build
dotnet run
```

## Learning Objective

To practice C# object-oriented programming, vehicle rental management, payment processing, and modern C# language features.
